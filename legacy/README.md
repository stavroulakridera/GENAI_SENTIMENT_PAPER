# Legacy / Historical Files

This directory preserves the original experiment files that existed at the repository root before the reproducibility reorganization.

## Contents

- `original_scripts/`: original historical Python experiment scripts, preserved without altering their historical content.
- `original_data/`: original root-level Twitter CSV files.

These files are retained for traceability and comparison with the reorganized repository.

For reproducible execution, use the organized scripts under `src/` and the datasets under `data/`.

Do not use the files in `legacy/` as the primary execution entry point.
